## 1. リーディングを攻略しよう presented by Hiro さん

### 1-1. Reading Part

- 60min
- 長文3題(900語前後)
- 問題形式
  - True / False / Not Given
  - 選択
  - Heading
  - Reference
  - 要約・穴埋め
  - etc.

### 1-2. 目指すスコア

- 目標総合スコアの+1を目指す。
- 本番中出来なかった問題は潔く忘れて次にすすむ
  - 解ける問題を取りこぼさないように時間を確保すること！

### 1-3. 攻略Tips

1. 単語
   - 3000語程度の単語帳で良い
   - あまりこの学習に固執しすぎない
3. 文法・語法・構文(5文型)
4. 問題慣れ
   - 一番大事
   - 速読の速さではなく、場数を踏んでいないから問題を解き終わらない

### 1-4. 時間内に解き終わるために

1. 読みながら解く
   - IELTSで聞かれるのはミクロ情報
   - 「本文を全部理解しよう」というスタンスを捨てる
     - あくまで問題を解いてスコアを取ることが目的 
2. 先読みする/先読みしない問題を見極める
   - 先読みする
     - True/False/Not Given
     - 選択問題
     - 要約・穴埋め
     - 図表
   - 先読みしない
     - Heading（のちにキーワードチェック）
     - Reference（のちにキーワードチェック）
     - 人物当て
3. 少量のキーワードを頭に入れておく
   - True/False/Not Given は順番通りに情報が与えられるので、1問ずつ先読みしてキーワードを頭に入れる
4. 解ける問題/解けない問題を見極める
   - 数字を見つける: ミクロ = 具体データの近くに答えが落ちていることが多い
   - 固有名詞を見つける
   - キーワードになりそうな単語を見つける
   - Reference や Heading は捨てる
     - 記号問題なので最悪適当に埋める

### 1-5. False/Not Given の見極め方

問題文に not を入れて本文のないようと一致すればその答えは False。

### 1-6. 学習計画

- 何をやるかを明確化する
- 時間をきちんと確保する
- 添削者を見つける
- スコアをあげるには時間がかかるので長期戦覚悟で焦らない
- 目標はスコアを取ることだと割り切る
